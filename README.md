# Twit AI on Cloudflare Pages

This is a migration-ready copy of `Arlemon987/twitai.site`. It keeps the existing static Twit AI website and moves API endpoints into Cloudflare Pages Functions.

See [CLOUDFLARE-MIGRATION.md](CLOUDFLARE-MIGRATION.md) for setup, secrets, Firebase requirements, and a deployment test checklist.

**Production safety:** this bundle does not change your live GitHub `main` branch, Vercel project, Netlify site, Firebase data, or DNS. Deploy it to a Preview environment first.
